# Matrix Client

Matrix Client is the renamed/reorganized MineFun.io **mod menu** built from the provided Celestar Mod Menu v2 project and the three provided addon scripts. It is not a bot and it is not a separate MineFun client/launcher.

## Included integrated mods

- Stopwatch — movable stopwatch and laps, Alt+K.
- Mouse Trail — trails, particles, click effects, emojis and pointer-lock settings, Alt+5.
- Display Enhancer — brightness, contrast, saturation, hue, gamma, temperature, vignette and scanlines, Ctrl+Alt.

The three addons are integrated into the same `registerMod(...)` menu system, with enable/disable cards and an Options entry that opens each addon’s detailed settings panel.

## Install

Install `matrix-client.user.js` in Tampermonkey. It loads the Matrix Client menu and the Matrix Client core from this repository.
